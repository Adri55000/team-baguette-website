# Ressources versionnées du backend

Ce dossier contient les ressources techniques livrées avec
Team Baguette et maintenues dans le dépôt Git.

- tracker_definitions/ : définitions fonctionnelles des trackers.
- tracker_presets/ : presets de trackers livrés avec le site.

Ces ressources sont intégrées aux images Docker.

Les uploads, packs importés et états live ne doivent pas
être stockés ici : ils utilisent le stockage persistant.
